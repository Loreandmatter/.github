# Support and Contact

**For article corrections:** See the [corrections policy](https://loreandmatter.com/en/corrections/) and submit the article URL, language, and supporting evidence through [Contact](https://loreandmatter.com/en/contact/).

**For editorial questions, permissions, or general feedback:** Use [Contact](https://loreandmatter.com/en/contact/).

**For technical issues:** Consult the applicable repository's README and issue policy. A public organization profile does not imply that every project or its source code is public.

**For security disclosures:** Follow [SECURITY.md](SECURITY.md), and contact the maintainers privately.

Do not include passwords, account credentials, private access tokens, or other sensitive personal information in public reports. No guaranteed response time applies.
